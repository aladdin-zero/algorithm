# algorithm

코딩 테스트 풀이 기록. AI 없이 푼다. 파일 맨 위 주석에 "왜 이 방법인가" 한 줄과 걸린 시간을 쓴다.

- `programmers/<번호>-<slug>.java` · `boj/<번호>.java`
- `patterns/<유형>.md` — 유형별 내 템플릿(BFS, 이분 탐색 경계, DP 점화식)
- `math/` — 그날 문제에 필요한 수학 노트(15분)
- `review-queue.md` — 재풀이 대기열 · `mock/YYYY-MM-DD.md` — 실전 세트 결과

## 한 파일 실행

```bash
java programmers/12345-example.java
```

클래스 이름이 파일 이름과 달라도 단일 파일 실행은 된다(JDK 11+). 커밋 메시지: `solve: programmers 12345 (32m, 재풀이 통과)`
